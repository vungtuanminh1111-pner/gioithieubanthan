# My Basketball World

Trang web giới thiệu bản thân theo chủ đề bóng rổ, sử dụng HTML, CSS và JavaScript thuần.

## Xem trang web

Mở [index.html](./index.html) trực tiếp trong trình duyệt, hoặc bật GitHub Pages:
1. Vào **Settings → Pages** trong repository.
2. Chọn **Deploy from a branch**.
3. Chọn branch **main**, folder **/ (root)** rồi nhấn **Save**.

## Nội dung và hiệu ứng

- Giao diện responsive với xanh navy, xanh dương, cyan và điểm nhấn cam bóng rổ.
- Hero section có bóng rổ chuyển động và quỹ đạo trang trí.
- Hiệu ứng reveal khi cuộn trang và tilt card khi rê chuột (desktop).
- Giới thiệu ngày sinh 01/01, cung Ma Kết, học tập THPT và sở thích bóng rổ.
- Các thẻ cầu thủ Stephen Curry, LaMelo Ball và Kyrie Irving.
